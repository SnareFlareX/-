# THE LAST LIGHT — Modrinth modpack (`.mrpack`)

**Fabric 1.21.11 · постапокалипсис · холодная атмосфера · редкие опасные встречи.**

Сборка собрана как настоящий Modrinth-пак: `modrinth.index.json` + `overrides/`,
все 39 файлов ссылаются на конкретные версии Modrinth с проверенными SHA-1/SHA-512.
Ни одного мода «на глаз» — каждая версия получена через API Modrinth в ноябре 2026.

```
THE-LAST-LIGHT-1.0.0.mrpack   ← готовый пак, импортируется в Prism Launcher
modrinth.index.json           ← исходник индекса (то же самое, что внутри пака)
build/                        ├── pack_data.py   — таблица файлов с хешами
                              ├── build.py       — сборка индекса и .mrpack
                              ├── verify.py      — статическая проверка
                              └── overrides/     — options.txt, iris.properties
```

> Важно: `.mrpack` **не содержит** самих JAR. Он содержит ссылки на CDN Modrinth и хеши.
> Prism скачивает моды при импорте — нужен интернет. Объём загрузки ≈ **115 МБ**
> (из них 64 МБ — Atmosfera со встроенными звуками).

## 2. Что я добавил от себя

Три мода, которых не было в исходном списке:

1. **AppleSkin 3.0.8** — показывает сытость и насыщение еды. В survival-хорроре это
   не «читерство», а честная информация: понимаешь, когда стоит вернуться на базу.
2. **Not Enough Animations 1.12.7** — анимации еды, карты, фонаря, лодки от первого лица.
   Дёшево по производительности и заметно добавляет «телесности» в пустом мире.
3. **Structory 1.3.17** — руины, башни и лагеря. Это прямая замена **Big Lost City**:
   у того нет сборки под 1.21.11 (только 26.1.x), а заросшие руины Structory дают тот же
   эффект «здесь когда-то жили люди».

## 3. Что не вошло и почему

| Мод | Причина |
|---|---|
| **Big Lost City** | Последняя версия — только `26.1 / 26.1.1 / 26.1.2`. Для 1.21.11 файла не существует. Заменён на Structory + Abandoned Structures. |
| **Mr The LURKER** (`eGABNYkk`) | Beta 1.0.0, «сильнее Wardena», спавн в тёмных местах. В основной профиль не ставлю — ломает баланс «редкой опасности». Если хочется: `mr-the-lurker-1.0.0.jar`, зависимости Fabric API + GeckoLib уже стоят. |
| **StaticVeil** (`0.2.1`) | Beta, singleplayer-only, меняет характер выживания. Тестировать отдельным экземпляром. |
| **Chunky** | Инструмент для выделенного сервера, в одиночной игре бесполезен. |
| **ModernFix / ScalableLux / C2ME** | Нет подтверждённой стабильной сборки под 1.21.11 в проверенном виде — не добавляю вслепую. |
| **LambDynamicLights** | Дублирует свет с Kefir's Flashlight; по твоему же условию — только отдельный тест. |
| **AmbientSounds** | Конфликтует с Atmosfera по звуковому ландшафту. |
| **When Dungeons Arise** | Нет сборки под 1.21.11 (проверено через API). |
| **Jade** | Осознанно не ставил: HUD с названиями блоков убивает ощущение неизвестности в хоррор-упаковке. Легко добавить отдельно (`Jade-1.21.11-Fabric-21.1.6.jar`). |

## 4. Установка

1. Открой **Prism Launcher → Add Instance → Import** (или просто перетащи
   `THE-LAST-LIGHT-1.0.0.mrpack` в окно Prism).
2. Prism сам поставит **Minecraft 1.21.11 + Fabric Loader 0.20.1** и скачает 39 файлов.
3. Проверь, что в `Настройки → Java` выделено **5–6 ГБ** памяти.
4. Первый запуск: Iris подхватит `Kefir's Flashlight` автоматически
   (это прописано в `overrides/config/iris.properties`).

Если Prism не подтянул шейдер — открой `Настройки → Video Settings → Shader Packs`
и выбери `Kefir's-flashlight.zip` вручную.

### Мир

- **Обычный мир** — генерируются руины Structory, заброшенные постройки, кладбища The Graveyard.
- **Город** — при создании мира выбери тип **Lost Cities**. Это отдельный мир-мегаполис,
  не смешивай его с обычным: генераторы не должны работать в одном мире одновременно.

> Генераторы мира не перестраивают уже исследованные чанки. Добавил мод — создавай новый мир.

## 5. Настройки под GTX 1050 3 GB

Уже зашито в `overrides/options.txt`:

```
renderDistance:8      simulationDistance:5      maxFps:120
enableVsync:false     gamma:0.0                 lang:ru_ru
```

Если FPS проседает в городе: `renderDistance:6`, в шейдере — низкое разрешение теней,
короткая дистанция теней, отражения выкл., AO выкл., рендер 0.75–0.85.

Три сцены для проверки: лес ночью, город днём, заброшенное здание с фонарём.

## 7. Проверка после установки

```bash
python3 build/build.py     # пересобрать индекс и .mrpack
python3 build/verify.py    # проверить хеши, пути, дубли, целостность zip
```

`verify.py` проверяет: 39 записей, корректные SHA-1 (40 hex) и SHA-512 (128 hex),
все URL с `cdn.modrinth.com`, нет дублей путей и выходов за пределы папки инстанса,
индекс внутри zip совпадает с `modrinth.index.json`.

**Что стоит сделать руками после первого запуска:**

1. `Mod Menu → Adam's Echo` — посмотри частоту событий; если слишком часто, уменьши вес.
2. `Mod Menu → The Graveyard` — при необходимости отключи отдельных мобов (`graveyard.json5`).
3. `Options → Video Settings → Shader Packs` — попробуй 4 профиля по очереди.
4. Если звук Atmosfera кажется громким — `Mod Menu → Atmosfera`, там громкость по слоям.

## 8. Обновление

Все версии зафиксированы в `build/pack_data.py`. Чтобы обновить мод, возьми свежую версию:

```
https://api.modrinth.com/v2/project/<slug>/version?game_versions=["1.21.11"]&loaders=["fabric"]
```

и перенеси `sha1`, `sha512`, `size`, `url` в таблицу. **Не меняй Sodium, не проверив Iris**:
Iris 1.10.8 требует именно Sodium `0.8.14` (`rkdTcxoT`).
