# MCFriend Customizer — Аддон настройки друга для мода `mcfriend` («Боря»)

Готовый аддон для **Minecraft 1.21.1 (Fabric)**, который позволяет быстро менять **имя**, **скин** и **фразы** друга из мода `mcfriend` («Боря») прямо в игре — через удобное окно на клавишу **`G`** или через чат-команды **`/друг`** (`/friend`).

---

## Готовые файлы для установки

В папке **`mods/`** лежат оба готовых `.jar` файла:

1. **`mods/mcfriend-1.0.0.jar`** — оригинальный мод `mcfriend` v1.0.0 (переименован из приложенного `mcfriend-1.0.0.txt` с проверкой контрольной суммы SHA-256).
2. **`mods/mcfriend-customizer-1.0.0.jar`** — новый аддон **MCFriend Customizer** v1.0.0.

### Установка

1. Убедитесь, что у вас установлен **Minecraft 1.21.1** с **Fabric Loader** (`>= 0.15.11`), **Java 21+** и **Fabric API**.
2. Скопируйте оба файла из папки `mods/` (`mcfriend-1.0.0.jar` и `mcfriend-customizer-1.0.0.jar`) в папку `.minecraft/mods/`.
3. Запустите игру — аддон заработает сразу!

---

## Как пользоваться в игре

Нажмите клавишу **`G`** (можно переназначить в *Настройки → Управление → McFriend*) или введите в чат **`/друг`**, чтобы открыть окно настройки с **4 вкладками**:

### 1. Вкладка «Имя»
- Мгновенно меняет имя друга **везде**:
  - в табличках окна друга (`B`) и дерева навыков (`K`) — вместо встроенного текста «Боря» аккуратно рисуется ваше имя;
  - в заголовке «Мешок …», в колесе диалога (`R`), в репликах над головой, в уведомлениях чата, подсказках навыков и титрах звуков;
  - опционально включает отображение таблички с именем прямо над головой друга.
- **Автоматические русские падежи** (именительный, родительный, дательный, винительный, творительный, предложный) — например: *Барсик → Мешок Барсика / Ответь Барсику / Позвать Барсика / С Барсиком*.
- При желании авто-падежи можно переключить в **ручной режим** и задать каждую форму самостоятельно.

### 2. Вкладка «Скин»
- **Быстрый выбор из папки**: положите любые `.png` скины в папку `config/mcfriend-customizer/skins/` (кнопка **«Папка скинов»** открывает её прямо из игры) и выберите нужный кликом — скин применяется мгновенно, без перезапуска игры!
- **Скачивание скина по нику Mojang или прямой ссылке PNG**: введите ник лицензионного игрока Minecraft (например, `Notch`) или URL картинки `.png` и нажмите **«Скачать и применить»** — аддон сам скачает скин, сохранит его в `skins/` и определит тип рук (Alex/Steve).
- Поддерживаются современные скины **64×64**, старые **64×32** (автоматически конвертируются в 64×64) и **HD-скины**.
- **Переключатель рук**: `Alex (3px, тонкие)` / `Steve (4px, обычные)`.
- **Кошачьи глаза**: можно отключить (выключается автоматически при выборе кастомного скина), чтобы анимированные жёлтые глаза Бори не перекрывали лицо вашего скина — при этом иконка в окне навыков (`K`) тоже обновляется под новый скин!

### 3. Вкладка «Фразы»
- **Поиск по всем 465 категориям реплик** оригинального мода (первая встреча, шахта, дерево, еда, бой, дом, реакции на мобов и т.д.).
- **Встроенный многострочный редактор**:
  - пишите по одной фразе на строку;
  - режим **«Замена»** (полностью заменить стандартные реплики категории) или **«+Добав.»** (добавить свои фразы к стандартным);
  - кнопка **«Сказать»** — друг сразу произнесёт фразу в пузырьке над головой для быстрой проверки;
  - кнопка **«.md»** — экспортирует категорию в файл `config/mcfriend-customizer/lines/<категория>.md` для удобного редактирования в любом текстовом редакторе, а кнопка **«Релоад»** сразу подхватывает изменения;
  - в своих фразах можно использовать подстановки: `{имя}`, `{кого}`, `{кому}`, `{винит}`, `{кем}`, `{оком}` (а также английские `{name}`, `{name_gen}`, `{name_dat}`, `{name_acc}`, `{name_ins}`, `{name_pre}`) и оригинальные теги мода вроде `[тебе]`, `[весело]`.
- **Глобальная автозамена слов**: быстро заменить любое слово во всех фразах сразу (например, `мяу → гав` или `кот → лис`) с сохранением регистра.

### 4. Вкладка «Профили»
- Сохраняйте готовые образы друга (**имя + скин + тип рук + глаза + все фразы + автозамены**) и переключайтесь между ними в один клик (например: *«Барсик»*, *«Стив»*, *«Лисёнок»*).
- Безопасная кнопка полного сброса к стандартному Боре (с подтверждением).

## Чат-команды (`/друг` и `/friend`)

Все команды поддерживают автодополнение по `Tab`:

| Команда | Что делает |
|---|---|
| `/друг` | Открыть окно настройки (клавиша `G`) |
| `/друг имя <НовоеИмя>` | Быстро сменить имя друга |
| `/друг имя сброс` | Вернуть имя «Боря» |
| `/друг скин <файл.png>` | Применить скин из папки `skins/` |
| `/друг скин скачать <ник_или_URL>` | Скачать скин по нику Mojang или ссылке `.png` |
| `/друг скин модель <slim\|classic>` | Переключить тонкие руки (Alex) / обычные (Steve) |
| `/друг скин глаза <true\|false>` | Включить или выключить кошачьи глаза |
| `/друг скин сброс` | Вернуть стандартный скин Бори |
| `/друг фраза сказать <текст>` | Заставить друга сразу сказать фразу |
| `/друг фраза задать <категория> <текст>` | Заменить фразы категории (`\|` разделяет несколько вариантов) |
| `/друг фраза добавить <категория> <текст>` | Добавить фразу к категории |
| `/друг фраза сброс <категория>` | Сбросить категорию к стандартным фразам |
| `/друг фраза экспорт <категория>` | Выгрузить категорию в `lines/<категория>.md` |
| `/друг фраза перезагрузить` | Перечитать все `.md` файлы без перезапуска |
| `/друг замена добавить <что> <на_что>` | Добавить глобальную замену слова |
| `/друг замена удалить <что>` | Удалить глобальную замену |
| `/друг замена очистить` | Очистить все глобальные замены |
| `/друг профиль сохранить <имя>` | Сохранить текущий образ в профиль |
| `/друг профиль загрузить <имя>` | Загрузить сохранённый профиль |
| `/друг профиль удалить <имя>` | Удалить профиль |
| `/друг профиль список` | Показать список профилей |
| `/друг сброс` | Сбросить все настройки к стандартному Боре |

## Файлы конфигурации и исходный код

Во время работы аддон автоматически создаёт папку:
```text
config/mcfriend-customizer/
├── config.json      # Текущие настройки (имя, скин, фразы, автозамены)
├── skins/           # Ваши .png скины (64x64, 64x32, HD)
├── lines/           # Пользовательские .md файлы фраз (перекрывают встроенные)
└── profiles/        # Сохранённые профили персонажей (.json)
```

Исходный код аддона находится в папке **`addon/`**.
